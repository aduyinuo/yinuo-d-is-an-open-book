# CMU Future Faculty Program

## Eberly Future Faculty Program

Through 2024–2025 I took part in Carnegie Mellon's Eberly Center Future Faculty Program — the structured version of learning to teach rather than the absorb-it-by-TA-ing version.

What it involved:

**Course design principles and pedagogy**, through a sequence of seminars — how to set learning objectives, align assessment to them, and design a class backward from what you want students to be able to do.

**Teaching feedback consultations** — observed teaching with structured feedback, which is the part that actually changes how you run a room.

**A course and syllabus design project** — building a full course from objectives through assessment, the deliverable that ties the seminars together.
