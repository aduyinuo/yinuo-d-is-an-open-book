# Next

Two questions run through this thread.

The first is whether the units used to describe problem-solving should be learned by an agent rather than specified in advance. In the work so far, the operations used to describe a solution are chosen by the researcher and then located in the data. An alternative is for an agent to learn its own operations as a set of reusable sub-behaviors, in the way hierarchical reinforcement learning learns options, or program-synthesis systems build and reuse a library of procedures. If the operations can be learned, their level of detail is determined by what proves useful rather than fixed in advance. A second part of this question concerns the control of the operations rather than the operations themselves: choosing which one to apply, recognizing when an approach is failing, and deciding when to stop. There is consistent evidence that people fail more often from poor control than from lacking operations, and control is the less understood of the two.

The second is whether inferring a cooperative partner's type and modeling an adversary's biases are the same problem. In both cases an agent estimates hidden properties of another agent from its behavior while that agent adapts in response. The two are currently studied separately, with different vocabularies. Whether they can be posed and solved as one problem, covering both cooperative and adversarial interaction, is open.
