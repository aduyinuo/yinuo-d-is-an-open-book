# Adversary

Defenders are trained against the attackers we can build. So what we build decides what they learn.

* [**Challenging Attacker**](adversary.md) — B-line and Meander on the same network: a fixed route straight at the objective, and a breadth-first sweep. A defender trained on one reads the other badly.
* [**Biased Attacker**](biased-attacker.md) — cognitive bias encoded as a reward structure rather than a hand-written rule, so loss aversion and risk aversion fall out of the value function.
