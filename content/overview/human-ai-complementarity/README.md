# Human-AI Complementarity

Putting a person and an agent on the same task does not make them a team. What makes them a team is the structure between them — who may approve what, what they share, what each learns from the other — and that structure is usually left implicit.

The work here makes it explicit enough to vary and measure.

* [**CHART**](chart.md) — a testbed where team structure is a directed graph, and the software enforces it: approvals route along control edges, explanations reach a panel, messages route by mention.
* [**Team Defense Game**](team-defense-game.md) — one human, one agent, one network, coupled by approval, a shared pool, and an agent that learns from moves it didn't make.
* [**CyberAgentTrace**](cyberagenttrace.md) — instrumenting agent workflows so their behaviour can be examined rather than inferred.
