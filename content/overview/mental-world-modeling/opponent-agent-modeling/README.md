# Opponent (Agent) Modeling

You cannot act well against someone you have no model of. The question is what kind of model, and how much of it can be learned from behaviour alone.

* [**Iterated Strategic Interaction**](social-intelligence.md) — cooperation and defection across a network, and how one agent compresses many partners into a few types, judged relative to each other rather than against a fixed bar.
* [**Adversary**](bias/) — two ways of building an attacker worth defending against.
