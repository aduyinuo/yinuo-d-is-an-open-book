# Artifacts

* [Astrolabe](astrolabe/) — represent problem-solving process as a hypergraph of mental operations and concepts, support both active guidance and passive monitoring & diagnose.
* [Daedalus](daedalus/) — a live cloud infrastructure of network emulation for reinforcement-learning based agent training and evaluation.
* [CHART](chart/) — a testbed for controllable human-AI teaming experiments&#x20;
* [Agentic Lab](agentic-lab/) — a cross-project & cross-product data collection tool for human-agent co-research.
