## Working claim
A useful taxonomy must classify strategic dependence by both **type** and **degree**, then remain stable when handed off to generator and learner stages.

## Seed lineages currently tracked

| Lineage | Sequential readiness | Representation lens | Current status |
|---|---|---|---|
| Graphical games | yes | graph structure | awaiting cross-stage validation |
| Influence-based abstraction | yes | state abstraction | awaiting object/causal mapping |
| Value-similarity abstraction | yes | EFG-facing lens | awaiting generation linkage |
| EITI / EDTI | yes | state + information view | awaiting recovery protocol choice |
| G2ANet attention lineage | yes | graph + learned gates | awaiting placement closure |

## Current taxonomy loop
1. Define candidate axes from common game properties (sequential, compositional, adversarial, heterogeneous, endogenous).
2. Place each definition on mostly orthogonal axes.
3. Score **coverage, exclusivity, parsimony, usefulness**.
4. Refine with add/split/merge/drop/re-bin operations.

## Open design decisions
- How to align payoff/strategy-space structure with MDP-side structure.
- Whether CK attack-set and strategy-clustering ideas fit existing axes or require new ones.
- Whether action-level vs strategy-level dependence should be an explicit axis.
