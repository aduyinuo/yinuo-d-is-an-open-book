## Why this subproject matters
Learn Structure is the LucidWorld subproject that turns strategic-dependence theory into a practical research pipeline. Its value is not a single model, but a traceable chain from definition to generation to learning to validation.

## Source structure used in this section

| Folder | Contribution |
|---|---|
| `Literature/` | dependence measures, axioms, graphical/causal grounding |
| `Notes/Latex/` | manuscript backbone (`main.tex`, `sections/*.tex`, references) |
| `Feedback/` | decision traces from meetings and revision cycles |
| `Submissions/` | packaging path toward external publication |

## Core objective
Build a reproducible workflow: **domain translation -> dependence planting/measurement -> structure learning -> recovery validation**, including explicit handling of unattainable requests.
