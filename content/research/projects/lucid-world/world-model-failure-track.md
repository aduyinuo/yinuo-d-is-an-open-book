# World Model Failure Track

## Focus
Identify and categorize failure patterns when learned world models are used in defense workflows.

## Core question
When does model error become strategically dangerous rather than merely predictive noise?

## Working buckets
1. representation mismatch
2. transition misestimation under adversarial shift
3. policy-model coupling failures
4. validation blind spots

## Next artifact targets
1. failure taxonomy v1
2. minimally reproducible failure scenarios
3. mitigation decision checklist
