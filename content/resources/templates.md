# Templates

Things I built for my own work and kept tidy enough to hand over.

## Lucid — a LaTeX beamer theme

A clean beamer theme for research talks: large type, sparse slides, one accent
colour, and no author or institution on any slide unless you switch it on — so
a deck can go to a double-blind venue without edits.

The demo deck is the manual. Every slide shows a component next to the code
that produced it, and each snippet also ships as its own file to copy from.
Compiles with pdfLaTeX; setup notes for Overleaf and VS Code are in the README.
