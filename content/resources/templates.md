# Templates

_**A LaTeX beamer theme for research talks:**_ large type, sparse slides, one accent color. The demo deck is the manual. Every slide shows a component next to the code that produced it, and each snippet also ships as its own file to copy from. Compiles with pdfLaTeX; setup notes for Overleaf and VS Code are in the README.
