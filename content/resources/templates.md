# Templates

_**A LaTeX beamer theme for research talks:**_ large type, sparse slides, one accent color, and no name or institution on any slide unless you switch it on. Open `main.tex` and start typing — it is a working deck, already set up. The demo deck is the manual: every slide shows a component next to the code that produced it, and each snippet also ships as its own file to copy from. Covers layout, figures, tables, math, code, citations, color, animation, speaker notes and hidden slides — notes and hidden slides each have a compiled and a not-compiled mode. A script converts a finished deck to PowerPoint. Compiles with pdfLaTeX; setup notes for Overleaf and VS Code are in the README.
