# Hybrid Artifacts Showcase

## Why this page
Some outputs are both research contributions and reusable tools. They should be represented in both narratives.

## Current and planned hybrid artifacts
- Astrolabe
- CTFTime Crawler
- Agentic Laboratory Collector
- MDP Generator (planned)

## Representation requirements
For each hybrid artifact:
1. Research contribution statement
2. Tool functionality statement
3. Diagram of method and workflow
4. Mockup or demo media
5. Reproducibility notes

## Suggested media strategy
- short demo GIF/video for interaction dynamics
- one architecture figure
- one "how this supports a research question" figure
