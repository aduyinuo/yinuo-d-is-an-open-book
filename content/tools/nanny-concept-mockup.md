# Nanny Concept Mockup

## Mission
Protect attention and body stability during immersive work without becoming another attention sink.

## Core loop
1. infer likely state drift (hydration, fatigue, strain, focus decay)
2. choose low-interruption intervention
3. collect one-tap feedback
4. adjust reminder cadence and threshold

## Interface blocks
- micro status strip (quiet)
- intervention card (actionable in < 10s)
- daily trend panel (optional)
- personalization controls

## Reminder components (extensible)
- hydration
- nutrition timing
- eye care
- posture and mobility
- nap/caffeine decision support

## Community extension model
Users can add reminder modules with:
- signal definition
- trigger logic
- intervention text templates
- feedback adaptation policy
