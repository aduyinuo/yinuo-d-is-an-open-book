# LinkedIn Notes Processor Mockup

## Mission
Capture fleeting insight from posts with minimal attention tax, then route it to the right project/person/opportunity context.

## Input modes
- URL + quick text note
- voice note transcription
- handwritten note import (image/PDF)

## Routing outputs
- research project subfolders
- opportunity pipelines
- people/contact folders
- reading group invite candidates

## Interface blocks
- quick capture
- classification review
- destination preview
- one-click route and archive
