# Artifacts

* [Astrolabe](astrolabe/) — turn recorded work sessions into coded, comparable, inter-rater-checked data. Runs on your machine; never touches your source files.
* [Daedalus](daedelus/) — a live cloud infrastructure of network emulation for reinforcement-learning based agent training and evaluation.
* [CHART](chart/) — a testbed for controllable human-AI teaming experiments&#x20;
* [Agentic Lab](agentic-lab/) — a cross-project & cross-product data collection tool for human-agent co-research.
