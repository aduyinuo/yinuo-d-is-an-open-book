# Artifacts

Tools that came out of the research and are worth using on their own. Each is real software with a real interface, not a figure — so each gets its own section: what it is, how it's built, and how you'd actually run it.

* [Astrolabe](astrolabe/) — turn recorded work sessions into coded, comparable, inter-rater-checked data. Runs on your machine; never touches your source files.
* [Daedalus](daedelus/) — a reinforcement-learning defender that deploys deception on live cloud infrastructure, with a fast simulator behind the same interface for training.
* [CHART](chart/) — a configurable testbed where the structure of a human–AI team is the thing you manipulate.
* [Agentic Lab](agentic-lab/) — a consent-aware substrate for recording and analysing researcher–agent interaction.
